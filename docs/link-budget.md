# 链路预算计算（§2.4 可复查）

> 自由空间模型推算，**不是**对 Nebula-7 工作频段的认定，也不是实测损耗。

## 输入

- 频率：2400.0 MHz（2.4 GHz ISM (assumption)）
- 距离：12.0 km
- 发射功率：30.0 dBm；Tx/Rx 天线：5.0 / 8.0 dBi
- 馈线/极化损耗：3.0 dB
- 带宽：5000000 Hz；NF=5.0 dB；所需 SNR=3.0 dB

## 结果

| 量 | 值 |
|---|---:|
| FSPL | 121.63 dB |
| 接收功率 | -81.63 dBm |
| 热噪声底 | -107.01 dBm |
| 灵敏度（估） | -99.01 dBm |
| **链路余量** | **17.38 dB** |
| 第一菲涅尔区半径（中点） | 19.36 m |
| 地球曲率隆起（估） | 2.12 m |
| 建议净空（半径+隆起） | 21.48 m |

## 解读

- 余量为正只说明**该窄带低阶调制工作点**在自由空间模型下成立；不能承诺同距离下的高码率视频。
- 必须分别做上下行预算，并与目标 MCS 灵敏度比较。
- 1.4 GHz 路损更小是物理结论，**不构成中国大陆可用性结论**（见方案 §3.3）。
